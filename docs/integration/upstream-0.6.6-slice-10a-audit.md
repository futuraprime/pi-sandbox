Neither count is a verification run in this audit.
- The pre-10 review's statement that C-13 remains a `test.todo` is stale: current `test/sandbox-runtime.test.ts:317` has an executable `characterizes upstream runtime read expansion for write allowances` test asserting configured and session write paths also enter effective read paths. `src/extension.ts:191,1231` consumes the shared effective read paths. The observed code/test behaviour is therefore “write allowance also grants effective read”; the ledger's product disposition is still marked deferred, so 10b should record an explicit disposition rather than silently treating a characterization test as approval.
- O-01 is already decided in the proposal and ledger for 10b (display-only `/sandbox`; editable `/sandbox-allow domain|read|write`); it is not implemented yet. The current registration remains the six-rule editor (`src/extension.ts:1381`, `src/sandbox-command.ts`; `test/sandbox-command.test.ts` covers its parser/writer). Existing editable prompt and scope tests are useful components, not replacement evidence for a `/sandbox-allow` command. Do not remove the editor before command registration, validation, abort, persistence, refresh, and protection contracts pass.
- O-06 says the `Alt+S` toggle is rejected and should be removed before release, but it remains registered at `src/extension.ts:1355`; the audit-time README advertised it without noting the rejection. O-04 remains deferred, but the implementation still accepts `sandboxUserShell: false` (`src/config.ts:15,40`; `src/extension.ts:1071`) and the updated README warns against use in untrusted projects. Treat these as known disposition/implementation mismatches; this audit does not change either decision or code.
- `origin/main`'s README contains downstream-specific documentation absent from the integration README, including linked-worktree allowances, the downstream read/write deny precedence, and Git/SSH and Chromium guidance (`git show origin/main:README.md`, sections “Linked Git worktrees” and “Git over SSH on macOS”). It is a useful source, not a drop-in final README: it predates the accepted credential boundary and Slice 9.5 transport details and itself flags earlier wording drift at its final notes.
